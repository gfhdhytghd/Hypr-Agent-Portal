# hypr-agent-portal

hypr-agent-portal is a stdio MCP bridge for background Computer Use on
Hyprland. The matching Hyprland plugin must be built, loaded, and enabled
before compositor screenshot or input operations can succeed.

Build and configuration instructions are in the
[project repository](https://github.com/gfhdhytghd/Hypr-Agent-Portal).
