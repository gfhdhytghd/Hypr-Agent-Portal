# hypr-agent-portal

hypr-agent-portal is a stdio MCP bridge for background Computer Use on
Hyprland. The matching Hyprland plugin must be built, loaded, and enabled
before compositor screenshot or input operations can succeed.

Version 0.5.0 pairs with the native plugin for Hyprland v0.57.2. Get the
plugin and build instructions from the
[matching release](https://github.com/gfhdhytghd/Hypr-Agent-Portal/releases/tag/v0.5.0-v0.57.2).
Upgrade both components together.

```sh
python3 -m pip install hypr-agent-portal==0.5.0
hypr-agent-portal
```
